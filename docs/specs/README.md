# Especificações de funcionalidades

Crie um arquivo `<id>-<nome-da-funcionalidade>.md` por incremento funcional, usando um nome curto no singular, como `01-gerenciamento-de-campanhas.md`. Use o [modelo](./TEMPLATE.md) e referencie os IDs da tabela do [MVP](../MVP.md) e as seções relevantes do [produto](../PRODUCT.md). Mantenha os IDs de critérios ao revisar a especificação.

Comece pelos comportamentos do incremento. Inclua os casos em que a operação falha e o estado que deve ser preservado. Se uma ambiguidade alterar comportamento observável, dados ou regras de negócio, registre a decisão pendente e leve-a para revisão. Com a especificação definida, associe os testes aos critérios e siga o [processo de desenvolvimento](../DEVELOPMENT.md).

As especificações de campanhas e sessões serão as primeiras antes do código da aplicação.
